## 1. 캠페인 OOH 전략 요약

본 캠페인의 옥외 매체는 **즉시 계약을 유도하는 대량 노출**이 아니라, 일본 サ高住·시니어 레지던스 **의사결정자(40~60대)의 업무 동선** 위에서 「人の時間を、人のために。」를 각인하고 **"도입 검토 목록 진입"**을 트리거하는 B2B 정밀 OOH로 설계합니다.

| 항목 | 방향 |
|------|------|
| **Primary Goal** | "루키 = 검증된 실내 서비스 로봇" 1차 인지 형성 |
| **메인 카피** | 「人の時間を、人のために。」 |
| **서브 카피** | 「1784で100台以上が動いている。」 / 「案内・運搬・配達、日常の「当たり前」を支える。」 |
| **CTA** | QR → JP 랜딩(1784 실증·파일럿 안내) / 백서 DL |
| **톤** | 따뜻함 + 실증 기반 차분한 자신감. 기술 스펙·과장 표현 배제 |

### 4-2. 비주얼 시나리오 (3 Act 구조)

**Act 1 — 공감 (0~3초 / 첫 시선)**

- **장면:** サ高住형 복도. 케어 스태프가 물품을 옮기며 바쁜 표정 → 컷 전환
- **메시지:** 「人の時間を、人のために。」 (텍스트 오버레이)
- **의도:** Pain Point "인력난·반복 업무"에 공감, 기술이 아닌 **사람의 시간** 프레이밍

**Act 2 — 실증 (3~8초 / 신뢰 형성)**

- **장면:** 1784 실내. 루키가 안내·운반·배달 수행. 스태프·방문객과 **자연스러운 공존** (로봇 단독 클로즈업 금지)
- **메시지:** 「1784で100台以上が動いている。」 / 「案内・運搬・配達、日常の「当たり前」を支える。」
- **의도:** "실험실이 아닌 실제 빌딩" — 첫 번째 실험 대상이 아니어도 된다는 안심

**Act 3 — 행동 유도 (8~15초 / 검토 트리거)**

- **장면:** 입주자와 스태프가 대화하는 따뜻한 컷. 파일럿 3단계 인포그래피 fade-in
- **메시지:** 「いきなり全面導入ではなく、小さく試せる。」 + QR·CTA
- **의도:** "계약"이 아닌 **"도입 검토"** 단계 행동 유도
