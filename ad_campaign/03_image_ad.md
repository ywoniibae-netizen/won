## 1. 비주얼 컨셉 (Visual Concept)

### 1-1. 컨셉명

**「先に、確かな現場がある。」** — *"먼저, 확실한 현장이 있다."*

의사결정자의 핵심 불안("우리가 첫 실험 대상이 되지 않을까?")을 해소하기 위해, **이미 검증된 공간(네이버 1784)**과 **일본 サ高住에 상상 가능한 따뜻한 현장**을 하나의 시각 서사로 연결합니다. 기술·로봇 단독 클로즈업이 아닌, **사람(스태프·입주자)과 로봇이 자연스럽게 공존하는 일상적 실내**를 중심에 둡니다.

### 1-2. 크리에이티브 원칙

| 항목 | 방향 |
|------|------|
| **무드** | 따뜻함 + 실증 기반의 차분한 자신감. SF·미래도시·게임적 톤 금지 |
| **색감** | 베이지·웜 화이트·소프트 우드·자연광. 1784의 모던 오피스와 サ高住의 목재·복도 톤을 브릿지 |
| **인물** | 40~60대 시설 관리자·케어 스태프, 70대+ 입주자. 자연스러운 미소·대화·동행 |
| **로봇(Rookie)** | 실내 서비스 로봇. 과장된 크기·공격적 디자인 지양. 복도·로비에서 **보조 역할**로 프레이밍 |
| **공간** | 밝고 깨끗한 실내 복도·共用部·ロビー. 일본 サ高住형 폭 좁은 복도·手すり·案内板 연상 가능 |
| **금지** | 로봇 단독 히어로 샷, 인력 대체·무인화 연상, "AI/자율주행" 텍스트 오버레이, 과장 수식어 |

### 1-3. 메시지–비주얼 매핑

```
     ↓

```

## 2. 메인 이미지 설명

### KV-01 — Hero Key Visual

**파일명 제안:** `rookie_kv01_hero_1784_coexistence.jpg`  
**비율:** 16:9 (마스터) · 1:1 · 4:5 · 1200×628 (LinkedIn) 파생

**장면 설명**

네이버 1784 스타일의 밝은 실내 복도. 왼쪽 전경에는 50대 여성 케어 스태프가 70대대 입주자(또는 방문객)와 눈높이에서 부드럽게 대화하며 미소 짓고 있다. 스태프 손에는 태블릿·클립보드 없음 — **"사람에게만 가능한 시간"**에 집중하는 연출.

중경 복도에는 Rookie 실내 서비스 로봇이 저속으로 이동하며, 상단 트레이에 생활용품·서류함을 실어 운반 중. 로봇 주변 다른 직원·방문객은 일상적으로 스쳐 지나가며 **특별히 주목하지 않는** 자연스러운 공존.

조명은 창측 자연광 + 따뜻한 실내 간접조명. 바닥·벽은 밝은 베이지·라이트 그레이, 목재 액센트. 전체 톤은 다큐멘터리 still — 과장된 색 보정·HDR 금지.

**카피 오버레이 (JP)**

- 메인: **「人の時間を、人のために。」**
- 서브(右下): **NAVER LABS Rookie** + 「案内・運搬・配達を支える室内サービスロボット」
- CTA(선택): 「資料ダウンロード」 / 「パイロット相談」

**의도**

"로봇을 사는 광고"가 아니라 **"스태프가 입주자와 마주하는 시간을 되돌려주는 운영"** 광고. AE 기획서의 핵심 인사이트("첫 실험 대상이 되지 않아도 된다")는 Hero 단독보다 SUB-02·SUB-03에서 보완.

## 3. 서브 이미지 설명

### KV-02 — サ高住 Contextual Adapt

**파일명 제안:** `rookie_kv02_senior_housing_jp_context.jpg`  
**비율:** 16:9 · 1:1

**장면 설명**

일본형 サービス付き高齢者向け住宅(サ高住)을 연상시키는 공용 복도. 좁지만 깨끗한 폭, 벽面 手すり, 案内看板, 우드톤 바닥. 창 없이도 부드러운 천장 간접조명.

중경에서 Rookie 로봇이 복도를 따라 이동하며, 60대 남성 시설 관리자(PM)가 로봇 옆을 지나며 태블릿을 보며 가볍게 고개를 끄덕이는 — **"도입 검토 중"**인 운영자의 시선. 원경에 80대 여성 입주자가 手すり를 잡고 천천히 걸으며, 로봇과 충돌 없이 여유 있게 공간을 공유.

**카피 오버레이 (JP)**

- 메인: **「人の時間を、人のために。」**
- 서브: **「サービス付き高齢者向け住宅の、新しい相棒。」**
- 보조: **「1784で100台以上が動いている。」**

**의도**

일본 의사결정자가 **자신의 시설 복도**를 떠올리게 하는 Contextual Visual. 1784 실증을 서브 카피로 연결해 "우리만의 실험이 아니다" 안심 제공.

---

### SUB-01 — 3 Roles Series (Carousel 3장)

#### SUB-01A · 案内 (Guidance)

**장면:** サ高住 로ビー. Rookie가 신규 입주자·가족 앞에서 로비 방향을 안내하는 제스처(디스플레이·음성 안내 연상). 스태프는 옆에서 보충 설명.  
**카피:** **「案内を、ロボットがサポート。」** / 「スタッフは、人にしかできない対話を。」

#### SUB-01B · 運搬 (Transport)

**장면:** 복도에서 Rookie가 세탁물·생활용품 수납함을 운반. 50대 스태프는 입주자 방 문 앞에서 맞이 준비.  
**카피:** **「運搬を、ロボットが担う。」** / 「重い荷物から、スタッフを解放。」

#### SUB-01C · 配達 (Delivery)

**장면:** Rookie가 개인실 앞에 소형 배달 트레이(약·간식·우편) 전달. 입주자는 문 앞에서 편안히 수령.  
**카피:** **「配達を、ロボットが届ける。」** / 「日常の「当たり前」を、確実に。」

**공통 비주얼:** 동일 색감·조명·인물 캐스팅. Carousel 좌→우 스와이프 시 **"안내 → 운반 → 배달"** 업무 흐름 인지.

### SUB-02 — 1784 Proof (실증 신뢰)

**파일명 제안:** `rookie_sub02_1784_proof.jpg`  
**비율:** 1:1 · 16:9

**장면 설명**

네이버 1784 넓은 아트리움·복도 원경. 다수(원근감상 3~5대, 텍스트로 100+ 표기)의 Rookie가 각자 경로를 이동. 사람(직장인·방문객) 밀도는 실제 오피스 수준 — **"실험실이 아닌 실제 빌딩"** 연출.

**카피 오버레이 (JP)**

- 메인(대안 B 활용): **「1784で100台以上。まず小さく、試せます。」**

**의도**

REIT·경영진 타겟. 감성 Hero(KV-01)와 달리 **팩트·숫자** 중심. 인포그래피 요소(100+ 아이콘, 1784 실루엣)를 후반 합성 가능.

## 5. 레이아웃 가이드 (Layout Guide)

### 5-1. Safe Zone & 그리드

| 매체 | 규격 | Safe Zone |
|------|------|-----------|
| LinkedIn Single Image | 1200×628 px | 텍스트·로고: 상하좌우 40px 이상, 하단 80px (UI 오버레이 대비) |
| LinkedIn Carousel | 1080×1080 px | 중앙 80% 텍스트 배치, 모서리 10% 이미지 여백 |
| 랜딩 Hero | 1920×1080 px | 좌측 40% 카피, 우측 60% 비주얼 (F-pattern) |
